# 右栏、消息搜索与后台任务

| 功能 | 命令 | 快捷键 |
| --- | --- | --- |
| 完全收起、恢复右栏 | `/side-panel` | `Ctrl+G o` |
| 明确收起、展开 | `/side-panel hide`、`/side-panel show` | 顶部 Hide / Show side |
| 全局消息内容搜索 | `/find [关键词]` | `Ctrl+G /` |
| 从搜索上下文返回最新消息 | `/live` | 点击上下文提示 |
| 后台任务总览 | `/tasks` | `Ctrl+G t` |

右栏显示状态按主会话保存，收起时保留布局、标签、草稿和任务。再次打开侧对话会恢复右栏。关闭最后一个侧视图也会收起右栏，撤销布局可以恢复。

搜索包含后端可读取的完整会话历史、归档记录与工具文本。首次搜索在后台分页建立 SQLite 索引，显示进度与错误计数；后续复用未变化的历史。按不区分大小写的原文子串匹配，支持中文及特殊字符，最多显示 100 条结果。Enter 打开命中上下文，`/live` 返回实时窗口，Esc 取消。未发送草稿不进入索引。

任务总览涵盖当前后台已知的运行中、排队、待审批、待回答、失败和状态未知的会话。Tab 切换状态筛选，输入文字筛选，Enter 打开会话，F2 打开所选待处理请求。浏览不会停止任务或释放 held 队列。独立外部进程持有的实时任务不在此列表中。

回归测试覆盖消息分页、归档与 Unicode 搜索、取消和替换、索引复用、上下文跳转、右栏恢复、任务筛选与审批入口，以及草稿、队列、任务的保留。测试通过隔离状态目录与模拟后端执行；真实后端测试只验证协议联通。
